## New Features

- Read-only WordPress abilities: `eventon-apify/get-status`, `eventon-apify/search-events`, and `eventon-apify/get-event`, in a new `eventon-apify` ability category. Abilities-aware clients (an MCP adapter, the WordPress AI client, or `/wp-json/wp-abilities/v1`) can check the API status, search events with pagination, and read one event without a custom integration. See "WordPress abilities" in the README.
  - They run the existing `eventonapify/v1` routes in-process, so the Event API switch, the per-operation toggles, argument handling, and error codes match the REST API exactly.
  - Execution requires `manage_options`, and non-administrators cannot discover them either: they are hidden from `wp_get_abilities()` and from core's abilities REST routes, matching the administrator-only MCP schema manifest.
  - Search returns event summaries only; `get-event` removes contact details, virtual access secrets, and notification emails. There are no write abilities.

## Improvements

- Uses WordPress 7.1's abilities features: the `public` exposure flag (so core lists and runs the abilities over REST, with schemas prepared by `wp_prepare_json_schema_for_client()`), and the `wp_get_abilities_item_include` filter for administrator-only discovery. Input is validated by core against bounded schemas (`per_page` 1-100, known statuses, no unknown keys).
- Tested up to WordPress 7.1.2. The CI integration job now installs WordPress 7.1.2 and also exercises the abilities end to end: parity with the REST routes, schema rejection, the toggles and master switch, REST discovery and run for administrators, and denial for subscribers.
- Static analysis uses the WordPress 7.1 stubs, and the PHPCS deprecation baseline is WordPress 7.1.

## Bug Fixes

- None.

## Notes

- Requires WordPress 7.1 or later (previously 7.0). Sites on WordPress 7.0 should stay on 3.4.0 until they upgrade. PHP 8.0 or later is unchanged; there is no PHP 7 support.
- No endpoint, payload, option, or capability behavior changes for existing REST, `wp/v2`, or MCP manifest clients.
