## Bug Fixes

- Register the wp/v2 compatibility routes regardless of the user resolved at `init`. Application-password auth resolves after `init`, so `show_in_rest` was always false for REST clients and the routes 404'd even for administrators. Access stays admin-only through the existing request-time guards.
