## New Features

- Event location payloads accept `image_ids` with one or two existing image attachment IDs. One integer is accepted as a single image, and an empty array clears saved images.
- Event reads include `location.image_ids` and full-size image URLs in `location.images`.

## Improvements

- The MCP manifest, OpenAPI document, and Postman example describe location images.

## Bug Fixes

- Venue images can now be saved through the event REST write path instead of requiring a separate edit in EventON's admin screen. Invalid image IDs return a 400 error before the event write begins.
